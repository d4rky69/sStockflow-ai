# Phase 3 Increment 5A — Forecasting Foundation

## Objective

Introduce a deterministic, auditable demand-forecasting foundation inside the Kotlin/Spring Boot core API. Numerical forecasts are generated by statistical models, not by an LLM.

## Delivered

- Flyway migration `V010__create_forecasting_foundation.sql`
- Tenant-level forecast configuration
- Forecast-run lifecycle and audit metadata
- Daily demand aggregation with zero-filled missing dates
- Four baseline models:
  - Naive
  - Moving average
  - Weighted moving average
  - Seasonal naive
- Rolling-origin backtesting
- MAE, RMSE, MAPE and bias
- Per-position best-model selection
- High, medium and low confidence classification
- Daily forecast values with lower and upper bounds
- Projected stockout date based on usable inventory
- Run exceptions for insufficient or unusable demand history
- REST APIs and integration tests

```text
GET  /api/v1/forecasts/summary
GET  /api/v1/forecasts/model-performance
GET  /api/v1/forecasts/stockout-projections
```

Every endpoint requires:

```http
X-Tenant-ID: TEN-ACME-PHARMA
```

## Start a seven-day forecast run

```cmd
curl -X POST ^
  -H "Content-Type: application/json" ^
  -H "X-Tenant-ID: TEN-ACME-PHARMA" ^
  -d "{\"asOfDate\":\"2026-07-26\",\"horizonDays\":7,\"historyDays\":180}" ^
  "http://localhost:8080/api/v1/forecasts/runs"
```

Run one warehouse and SKU:

```cmd
curl -X POST ^
  -H "Content-Type: application/json" ^
  -H "X-Tenant-ID: TEN-ACME-PHARMA" ^
  -d "{\"asOfDate\":\"2026-07-26\",\"horizonDays\":30,\"historyDays\":180,\"warehouseId\":\"WH-CHENNAI\",\"skuId\":\"SKU-PARA-650\"}" ^
  "http://localhost:8080/api/v1/forecasts/runs"
```

## Model selection

Each model is backtested against recent actual demand. The selected model has the lowest MAPE; MAE and model code are deterministic tie-breakers. MAPE is omitted when every actual value in the backtest window is zero.

## Confidence

- `HIGH`: MAPE ≤ 15% and at least 60 history days
- `MEDIUM`: MAPE ≤ 30% and at least 28 history days
- `MEDIUM`: zero-denominator MAPE with MAE ≤ 5 and at least 60 history days
- `LOW`: all other cases

## Bounds

The initial confidence interval is:

```text
forecast ± 1.96 × backtest RMSE
```

The lower bound is never negative.

## Current boundary

This increment does not create purchase orders, transfers or autonomous actions. Gemini will later explain forecast and optimization outputs; it will not calculate the numerical forecast.
